# VN100 econometrics run — ROBUSTNESS_EX_FINANCIALS

## Inputs and sample

- Returns: `outputs/vn_period_factors_ex_financials/vn100_returns_clean.csv`; factors: `outputs/vn_period_factors_ex_financials/vn100_factors_monthly.csv`. Source commit `57c916834b8d6dbf32d02f81df271162884dbeb4`; tracked-blob verification: `False` (custom input paths).
- Exactly 30 assets and 60 common monthly observations (2021-07-31 to 2026-06-30). All three models and all three GRS tests use this same sample.
- Return, RF, and factors are decimals in the input. `run_factor_regression()` subtracts RF once. CAPM uses MKT_RF; FF3 uses SMB; FF5 uses the separate SMB_FF5 plus HML, RMW, CMA.
- MKT uses `VN100`. MKT_RF is recomputed from the monthly VN100 return column in the matched return panel minus the Factor Team RF.
- RF remains the Factor Team's effective monthly conversion from a 1Y yield. Factor schedule: `annual_july`; weighting: `lagged_market_cap`; financial firms in factor sorts: `excluded`.
- Universe selection: Top 30 non-financial VN100 members by formation market capitalization at 2021-06-30; financials excluded from LHS; sample starts 2021-07. The Econometrics Team chose the June 2021 formation market-cap rule before the July 2021–June 2026 return window; status: `group-approved`.
