# VN100 econometrics run — ROBUSTNESS_SEMIANNUAL

## Inputs and sample

- Returns: `outputs/vn_period_factors_semiannual/vn100_returns_clean.csv`; factors: `outputs/vn_period_factors_semiannual/vn100_factors_monthly.csv`. Source commit `57c916834b8d6dbf32d02f81df271162884dbeb4`; tracked-blob verification: `False` (custom input paths).
- Exactly 30 assets and 59 common monthly observations (2021-08-31 to 2026-06-30). All three models and all three GRS tests use this same sample.
- Return, RF, and factors are decimals in the input. `run_factor_regression()` subtracts RF once. CAPM uses MKT_RF; FF3 uses SMB; FF5 uses the separate SMB_FF5 plus HML, RMW, CMA.
- MKT uses `VN100`. MKT_RF is recomputed from the monthly VN100 return column in the matched return panel minus the Factor Team RF.
- RF remains the Factor Team's effective monthly conversion from a 1Y yield. Factor schedule: `supplied_semiannual`; weighting: `lagged_market_cap`; financial firms in factor sorts: `included`.
- Universe selection: Top 30 VN100 members by June 2021 formation market cap; sample starts July 2021. The Econometrics Team chose the June 2021 formation market-cap rule before the July 2021–June 2026 return window; status: `team-baseline`.

- OLS alpha/t, factor betas, and R² for every stock/model are in `table7_style_assets.csv` and `asset_model_summary.csv`; coefficient-level OLS and HAC lag 12/6 estimates are in `coefficient_detail.csv`.
- VIF rows above the project threshold 10: 0. Values are in `vif.csv`.
- FF5 R² is below FF3 R² for 1 of 30 assets: PDR.HM. This can occur because FF5 uses SMB_FF5 rather than the FF3 SMB series.
- HML spanning regression (HML on MKT_RF, SMB_FF5, RMW, CMA): alpha 0.5625%/month; OLS t 0.6992; HAC lag-12 z 1.0096. Full p-values are in `hml_redundancy.csv`.
