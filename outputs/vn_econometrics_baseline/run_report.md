# VN100 econometrics run — KTL_BASELINE_JUNE_2021_FORMATION_TOP30

## Inputs and sample

- Returns: `outputs/vn_period_factors/vn100_returns_clean.csv`; factors: `outputs/vn_period_factors/vn100_factors_monthly.csv`. Source commit `926f53deaaf0c9cc2e75a540fb789eb1f811d82a`; tracked-blob verification: `True` (matched tracked Git blobs).
- Exactly 30 assets and 60 common monthly observations (2021-07-31 to 2026-06-30). All three models and all three GRS tests use this same sample.
- Return, RF, and factors are decimals in the input. `run_factor_regression()` subtracts RF once. CAPM uses MKT_RF; FF3 uses SMB; FF5 uses the separate SMB_FF5 plus HML, RMW, CMA.
- MKT uses `VN100`. MKT_RF is recomputed from the monthly VN100 return column in the matched return panel minus the Factor Team RF.
- RF remains the Factor Team's effective monthly conversion from a 1Y yield; portfolio formation is June with July-to-June holding and lagged total market-cap weights. See `docs/vn_econometrics_method_choices.md` for the baseline method and its basis.
- Universe selection: Top 30 VN100 members by June 2021 formation market cap; sample starts July 2021. The Econometrics Team chose the June 2021 formation market-cap rule before the July 2021–June 2026 return window; status: `team-baseline`.

At the 5% level, the GRS p-values do not reject the joint zero-alpha null for CAPM, FF3, or FF5 in this 30-stock, 60-month sample. This is a failure to reject for this sample, not proof that a model is true.

## Inference and diagnostics

- OLS alpha/t, factor betas, and R² for every stock/model are in `table7_style_assets.csv` and `asset_model_summary.csv`; coefficient-level OLS and HAC lag 12/6 estimates are in `coefficient_detail.csv`.
- VIF rows above the project threshold 10: 0. Values are in `vif.csv`.
- FF5 R² is below FF3 R² for 1 of 30 assets: PDR.HM. This can occur because FF5 uses SMB_FF5 rather than the FF3 SMB series.
- HML spanning regression (HML on MKT_RF, SMB_FF5, RMW, CMA): alpha 0.8097%/month; OLS t 1.0480; HAC lag-12 z 1.1109. Full p-values are in `hml_redundancy.csv`.
- Selected returns use source counts {'close_eom': 1800}. Reported-vs-price return gaps above 1 percentage point in selected rows: 7. These are retained as audit flags.
